# Historial de versiones

## Enterprise 1.0.0

- Consolidación del proyecto real publicado.
- Cliente HTTP reutilizable para Odoo.
- Consultas de Inventario, Producción y Ventas ejecutadas en paralelo.
- Caché operativo de 45 segundos para evitar consultas repetidas.
- El botón “Actualizar ahora” fuerza una consulta nueva.
- Corrección de límites de fecha de Chihuahua a UTC.
- Históricos diarios actualizados durante el día, no congelados en la primera consulta.
- Validación de parámetros de API.
- Endpoint de salud sin exponer datos sensibles.
- Pruebas automáticas ampliadas.
- Limpieza y consolidación de documentación.
